# 提示词组合注入器 (`astrbot_plugin_prompt_injector`)

支持在 AstrBot 每次发起 LLM 请求时，在 **人格设定前**、**人格设定后**、**用户最新输入前**、**用户最新输入后** 4 个核心位置注入一个或多个（具体数量可设置）提示词。

## ✨ 核心特性

1. **四位置精准注入（支持多条提示词有序拼接）**：
   - **人格设定前 (`before_persona`)**：精准定位 AstrBot 的 `# Persona Instructions` 人格设定区块，在其紧前方按排序注入一条或多条提示词。
   - **人格设定后 (`after_persona`)**：在人格设定正文结束后（且在后续内置技能/工具说明前）按排序注入一条或多条提示词。
   - **用户最新输入前 (`before_user`)**：在当前回合用户最新输入（`req.prompt`）前方按排序注入一条或多条提示词。
   - **用户最新输入后 (`after_user`)**：作为当前回合用户最新输入后的附加内容块（`req.extra_user_content_parts`）按排序注入一条或多条提示词（默认标记为 `temp` 仅当次请求生效，不污染持久化历史记录，也可开启写入历史）。

2. **可视化拖拽调整编辑面板（双入口支持）**：
   - **专属可视化编排面板 (Plugin View)**：在 AstrBot WebUI 插件管理页进入本插件详情页，或从左侧导航栏的「插件可视化视图 -> 提示词编排面板」进入。
   - **直观锚点同屏排序**：「🔒 **人格设定 (Persona)**」与「💬 **用户最新输入 (Latest User Input)**」直接作为核心锚点卡片呈现在排序流中！您可以直接拖拽提示词卡片或锚点卡片上下移动，实时预览完整组装后的 `System Prompt` 与 `User Prompt`。
   - **原生配置表单 (`_conf_schema.json`) 双向同步**：在插件的「配置」弹窗中同样基于 `template_list` 呈现包含「人格设定」与「用户最新输入」锚点的嵌套列表，任何一处修改均实时同步。

3. **多提示词组合 (Presets) 与自由切换**：
   - 支持创建任意多个提示词组合（例如：「日常闲聊组合」、「角色扮演强化组合」、「严谨工作组合」），每个组合拥有独立的排序流与会话生效范围（全部会话 / 仅群聊 / 仅私聊）。
   - 支持在可视化面板中一键切换当前生效组合、复制组合、JSON 导入/导出，或通过管理员指令 `/pi switch` 随时切换。

4. **可配置的数量上限与动态变量**：
   - 可自由设置每个位置允许注入的最大提示词数量（`0` 表示不限制），超出上限的条目会在可视化面板中自动高亮提示。
   - 支持动态变量替换：`{user_name}`、`{user_id}`、`{group_id}`、`{date}`、`{time}`、`{datetime}`、`{weekday}`、`{umo}`。

---

## 💬 管理员指令

| 指令 | 说明 |
| --- | --- |
| `/pi list` | 查看所有提示词组合列表、各位置生效条数及当前激活状态 |
| `/pi switch <名称或序号>` | 自由切换当前生效的提示词组合（别名：`/pi 切换`） |
| `/pi detail [名称或序号]` | 查看指定组合的完整排序流（含人格设定与用户最新输入锚点位置） |
| `/pi limit <数量>` | 设置单位置最大注入提示词数量（`0` 表示不限制） |
| `/pi toggle` | 开启或关闭提示词注入器总开关 |
